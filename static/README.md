# Static Assets

This folder contains static CSS/JS used by the Flask app and frontend.

Quick preview

```bash
cd static
# Serve files on port 8000 for a quick preview
python3 -m http.server 8000

# Then open http://localhost:8000
```

Files
- `styles.css`, `C.css`, `Jscrpt.js` etc. are used by templates in `templates/`.
